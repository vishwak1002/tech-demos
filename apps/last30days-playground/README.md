# last30days-playground

DevRel playground for the [Last 30 Days](https://github.com/mvanhorn/last30days-skill) research-skill idea: topic → mock multi-source scan → cited synthesis brief. No API keys.

## Design Read

Editorial research desk for DevRel / technical advocates — warm paper canvas, Newsreader headlines, Geist body/mono metadata, forest accent; not purple AI-chat chrome.

## Run

```bash
cd apps/last30days-playground
bun install
bun run dev
```

```bash
bun run build
```

## Demo tips

- Use a sample chip for the happy path.
- Topic `fail` forces the error state.
- Clear returns to the empty desk.
